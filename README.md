## 开源原则 · Open-source principles

- **实用优先 · Useful first** — 解决自己每天真正遇到的问题
- **隐私友好 · Privacy-minded** — 尽量本地处理，不收集不必要的数据
- **简单可靠 · Simple and reliable** — 保持清晰的界面与可理解的实现
- **文档完整 · Well documented** — 提供中英双语说明、构建步骤和更新记录
